# ForgeJS Architecture

ForgeJS is divided into four major layers.

## Editor

The development environment.

Responsible for:

- Scene editing
- Hierarchy
- Inspector
- Assets
- Visual scripting
- Viewport
- Project management

## Engine

Runtime responsible for:

- Entities
- Components
- Scenes
- Rendering
- Physics
- Audio
- Input
- Animation

## Visual Scripting

Graph-based programming system.

Graphs contain:

- Nodes
- Execution pins
- Data pins
- Connections
- Variables
- Events

## Project

A ForgeJS project contains:

- Scenes
- Assets
- Visual scripts
- Materials
- Models
- Textures
- Audio
